## 주요 검사

- boost의 /uː/ 토큰 1개 → JV-U 요소 2개.
- cats의 /t+s/ 토큰 2개 → JV-TS 1개, 음절 경계를 가로질러 합치지 않음.
- play·blue·hello에서 /l/을 중복 소비하지 않음.
- FOOT와 U U, GA AW와 RP O O의 대립 보존.
- 미배당 종성 5개는 구조에 남기고 단어 전체 평문 출력을 중단.
- GA /ɝ/와 음절자음에 임의 모음 삽입 없음.
- GA /ɚ/의 원문과 /əɹ/ 정규화 이력 보존.
- 강세·원문·출처가 평문만으로 보존된다고 주장하지 않음.
- 잘못된 부호 순서·채움문자·참조·중복 소비 거부.
- 점 경계 우선, 자동 음절 분석의 검토 필요 상태 표시.
- 사전 요청 실패 후 재시도 가능, 없는 단어에 발음을 생성하지 않음.
- 제2본 맺음말의 car·go·pass·hot·near와 §7 대조표가 RP·GA 문서 예시를 우선 사용함.
- 표시층은 종성 /s/·/t+s/를 독립 요소로 보여 금지형 `팻`·`캧`을 만들지 않으며, 복사·저장 NFD는 바꾸지 않음.
- 제3본 §21의 RP 207·447종, GA 123·303종과 등록·미등록·미배당 수치를 `tools/cluster_census.mjs`로 재현함.
