# 훈민바름 영어확장판 · 2026-09-16 편집·검증 내역

## 결과물

제1본 36쪽, 제2본 59쪽, 제3본 46쪽, 제4본 23쪽을 각각 정식 읽기 단위로 확정했다. 네 권을 같은 순서로 합친 164쪽 PDF는 전체 연구 기록·보관용 통합판으로 두었으며, 각 권의 첫 페이지로 이동하는 책갈피 네 개를 넣었다.

## 제1·2본

최신 DOCX 편집 원본은 확보되지 않았다. 2026-09-08 기준 PDF에 2026-09-14 작업파일의 검증된 교정 127건을 다시 적용했으며, 덧씌운 글자의 글꼴을 나눔명조 옛한글로 통일했다. 기존 쪽수와 페이지 크기는 유지했다.

주요 교정은 제1본의 음소토큰–자모 요소 대응 설명과, 제2본의 `/s/` 위치 설명, 역변환 범위, §9.3의 ㄹ 중복 예시, 강세·운율 조건이다. 세부 문구는 [2026-09-08 교정 내역](HMBR_Corrections_20260908.md)에 기록되어 있다.

## 제3본

- §20.1에 기술적 표현 불가능성과 법적 금지를 구분하는 한정 문구를 반영했다.
- §21의 ‘재검증 대기’를 해제했다. `tools/cluster_census.mjs`와 저장소의 RP·GA 사전으로 표 수치를 재현했다.
- 종성 `/t+s/` 한 종을 `compound_ts`로 따로 세어 소계가 총계보다 1종 작아 보였던 이유를 명시했다.
- 부록 C에 실행 명령, 자료, 해시 확인과 인용 한계를 기록했다.
- 수정한 DOCX 원본과 그 원본에서 다시 출력한 PDF를 함께 제공한다.

## 제4본

- 중복 최상위 제목을 ‘계속’ 표제로 정리하고 목차를 맞췄다.
- 화면 표시를 `linear-trial-v2`로 갱신했다. 합성 핵 100%, 뒤 모음 50%, 독립 자음 75%이며 종성 `/s/`와 `/t+s/`는 독립 요소로 표시한다.
- 복사·저장되는 NFD 직렬화는 표시 변경과 무관하게 보존됨을 명시했다.
- 시험 결과를 270/270으로 갱신하고 검사·빌드·전수조사·Pages 실행 근거를 반영했다.
- 수정한 DOCX 원본, Markdown 변환본과 PDF를 함께 제공한다.
