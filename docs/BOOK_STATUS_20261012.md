## 근거와 한계

기존 네 PDF의 t·Narrow·연결 발음·구현 관련 구절을 읽고 소스 코드와 대조했다. 외부 본문과 문자 IPA 확인 범위, 실패한 접근, 출처별 제한은 [연결 발음 SOURCE AUDIT](CONNECTED_SPEECH.md#추가-source-audit)에 기록했다. 오디오를 청취 검증하지 않았다. 추천 속도·우선순위는 앱의 편집 정책이다.

자동시험 307개가 통과했다. 단어별 선택과 되돌리기, 강세·쉼 조건, 원형 불변, 미결 자형의 원형 참조를 검사했다. 해당 시험은 학습 효과나 모든 GA 화자의 발음 일치를 보증하지 않는다. GA winter의 /r/ 누락은 단일 항목으로 보완했으며 일반 사전 전수 검수는 아니다.

자동 flapping, 임의의 Narrow 입력 변환, 문장 억양, TTS 재생은 아직 제공하지 않는다. 다음 TTS 단계는 선택된 표면형과 실제 음성의 일치 여부를 검증해야 한다. MP 문서는 이번 출판에서 제외했다.

최종 파일 목록은 [문서 색인](INDEX.md), 파일별 해시는 [체크섬](../SHA256SUMS.txt), 종전 상태는 [10월 9일 상태 검토](BOOK_STATUS_20261009.md)에서 확인한다.

PDF 38·62·48·26쪽과 합본 174쪽, DOCX의 같은 개정 내용을 확인했다. 네 DOCX를 렌더링해 전 페이지의 배치를 검토했고, 기존 PDF 본문 161쪽은 추가 안내문 아래의 화면 픽셀이 종전 판과 같음을 검사했다. 책 표지·부록의 한글과 IPA 표시도 확인했다.
