# 2026-09-17 저자 결정 반영

저자는 한국어 독자가 초성 없는 모음을 별도 낱자로 오인하지 않도록 `부ㅜㅅㅌ` 대신 `부우ㅅㅌ`을 읽기용 표기로 사용하도록 결정했다. 장모음·복모음의 뒤 모음에 무음 초성 ㅇ을 붙이며 옛한글 모음에도 같은 원칙을 적용한다. 이 ㅇ은 같은 음절핵을 읽기 위한 표시용 자리다. 새 음소·음절을 추가하지 않는다.

## 앱과 데이터

`linear-trial-v8-vowel-carrier`는 부우ㅅㅌ·카아·파아ㅋ·ㅂ루우처럼 표시한다. 옛한글 모음과 무음 초성도 하나의 렌더링 단위로 유지한다. 핵의 크기와 뒤 모음·독립 자음의 비율은 유지한다: boost는 부 100%, 우 50%, ㅅ·ㅌ 각각 75%다. 제2강세가 있는 단어에서만 제1강세 핵을 125%로 표시한다.

정본 모델, 자모값, 음소 수, 음절 경계와 NFD 직렬화는 바꾸지 않는다. 예를 들어 boost의 저장 부호열은 `U+1107 U+116E U+116E U+11BA U+11C0`이다. 앱의 자모열 복사는 이 기준형을 사용한다. 읽기용 표기를 저장 기준형으로 오인하지 않도록 제3·4본의 설명을 함께 고쳤다.

제2본의 최신 DOCX는 확보되지 않았다. 따라서 편집 원본을 새로 내보낸 판본이라고 부르지 않는다. 기준 PDF의 위치와 쪽수를 유지해 수정했다. 원 PDF의 일부 글꼴은 문자 코드와 글리프 대응이 불안정해 직접 삭제·재인코딩하면 인접 글자가 손상됐다. 수정된 30쪽은 확인한 글자 윤곽을 벡터로 보존하고 수정 문언을 반영한 텍스트층을 넣었다. 가려진 구판 문언이 검색 결과에 중복되는 방식은 사용하지 않았다. 옛한글 합성 예는 PDF 추출 문자열만으로 판단하지 않고 렌더링으로 대조한다.

제3·4본은 DOCX를 직접 수정한 뒤 PDF로 다시 내보냈다. 제4본 Markdown도 같은 문언으로 갱신했다. 종전 실험·사전 집계·배포의 날짜와 커밋은 해당 시점의 기록으로 유지한다. 과거 판본 파일은 보존한다.
