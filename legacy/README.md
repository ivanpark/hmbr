# 훈민바름 Web

IPA 를 옛한글 자모에 1:1 로 대응시켜 적는 웹 앱. 빌드 도구 없이 돌아가는
정적 ES 모듈 사이트다.

기준 문서는 **표기규격 v2.0** — 특히 「음소–자모값 대응 등록부」(제19조 ⑨,
마스터 표 15 · 별첨 표 11)와 제5조의2 다. 화면(index.html, css/style.css)은
v4 의 것을 그대로 두고, 대응표와 엔진과 시험만 v2.0 으로 옮겼다.

## 돌리기

```
python3 -m http.server 8000
```

http://localhost:8000 을 연다. 빌드도, npm 도, 프레임워크도 없다.
`file://` 로 열면 동작하지 않는다 — ES 모듈과 사전 `fetch` 가 http 를 요구한다.

## 시험

```
node tests/spec.test.mjs          # 규격 적합성 — 여기부터 본다
node tests/test.mjs               # 엔진 전반
node tests/modes.test.mjs         # 넓은/좁은 × 낱말/이어말하기
node tests/articulation.test.mjs  # 조음 안내 카드
```

넷을 합쳐 115 개의 확인이 돌아간다. `spec.test.mjs` 는 등록부와 부록 E 의
시범 어휘 열넷을 부호점 그대로 못박은 것이고, `webapp/hmbr_convert.py` 의
자체시험 표와 값이 같다.

기대값은 글자꼴이 아니라 **부호점**으로 적는다. 조합용 자모는 터미널에서
서로 비슷하게 그려져 눈으로는 맞다 틀리다를 가릴 수 없다. 견줄 때는 양쪽을
NFD 로 푼다 — 엔진은 KS X 1026-1 이 받는 자리에서만 음절을 모으므로
모인 꼴과 풀린 꼴이 섞여 나온다.

## 짜임새

| 파일 | 하는 일 |
|------|---------|
| `index.html` | 화면 (v4 그대로) |
| `css/style.css` | 해례본 결 — 먹빛 남색 바탕, 한지 출력면 (v4 그대로) |
| `js/registry.js` | 등록부를 기계가 읽는 꼴로 옮긴 것. **손으로 고치지 않는다** |
| `js/map.js` | 등록부에서 끌어낸 대응표 — 유일한 근거 |
| `js/engine.js` | ipaToJamos → jamosToSyllables → toRuns |
| `js/articulation.js` | 조음 안내 카드 |
| `js/connected.js` | 이어말하기 규칙 (IPA → IPA) |
| `js/render.js` | DOM 그리기 (v4 그대로) |
| `js/dict.js` | 영어→IPA 사전 늦불러오기 (v4 그대로) |
| `js/app.js` | 잇기 |
| `tools/gen_registry_js.py` | 등록부 JSON → `js/registry.js` |

`js/registry.js` 는 `tools/gen_registry_js.py` 가 `webapp/` 의 등록부
산출물에서 만들어 낸다. 등록부가 바뀌면 이 스크립트를 다시 돌린다.

데이터: `data/dict-ga.json` 125,004 항목(CMU 계열), `data/dict-rp.json`
135,495 항목(2023년에 일부 기계 생성 — 검수 전).
글꼴: 나눔명조·나눔바른고딕 옛한글을 훈민바름이 닿는 글자에만 줄인 woff
두 벌, 합쳐 약 2.0 MB. brotli 를 걸어 woff2 로 바꾸면 다시 절반쯤 된다.

## 정본과 표시를 가른다

규격이 정하는 것은 **저장·교환되는 부호열**이지 그것을 화면에 어떻게 모아
보이느냐가 아니다. 앱은 이 둘을 갈라 다룬다.

- **정본** `convert().canonical` — 조합용 자모 그대로. 호환용 자모
  U+3130–U+318F 는 정본에 넣지 않는다. 자리(초성·중성·종성) 정보가 사라지면
  역변환도 정규화도 무너지기 때문이다.
- **표시** `convert().text` — 표시 프로파일을 태운 가독형. ᆝ(U+119D) 를
  ᅵ(U+1175) 로 접은 뒤 NFC 로 모은다.

`pick /pɪk/` 의 정본은 U+1111 U+119D U+11BF 이고 화면에는 핔(U+D554)으로
나온다. 접힌 자모는 되돌릴 수 없으므로 **복사 단추는 정본을 내보낸다.**
화면에 보이는 것을 그대로 복사하면 ᆝ 가 사라진다.

## v2.0 이 v1.2 에서 바꾼 자리

- **원어 종성 직접 보존**(제5조의2 ④) — 한국어 말음 중화를 적용하지 않는다.
  pick 은 ᆨ 이 아니라 ᆿ, cup 은 ᆸ 이 아니라 ᇁ, soot 은 ᆮ 이 아니라 ᇀ,
  pass 는 ᆮ 이 아니라 ᆺ.
- **어말 자음군** — v1.2 가 끼워 넣던 모음 음절을 종성열로 편다.
  boost 는 부웃드가 아니라 부우ᄉᇀ (RV-EN-CLUSTER-01).
- **/s/ 의 문맥별 위치형**(제5조의2 ②③) — 자모값은 하나인데 부호열이 넷이다.
  그 밖의 모음 앞 ᄊ, 고원순모음 /uː ʊ/ 앞 ᄉ, 자음 앞 ᄉ+채움중성, 종성 ᆺ.
  고원순 경계는 **시범규칙**이며 대조시험 결과에 따라 움직일 수 있다.

## v4 의 미결 사항 가운데 등록부가 정한 것

- **[R1]** /θ/ → **ᅅ U+1145**
- **[R2]** /ð/ → **ᅂ U+1142**
- **[R3]** 좁은 표기에서 /s/ 뒤 무기 파열음 → **ᄈ/ᄄ/ᄁ**
- **[R4]** /ɔ/ → **ᆂ U+1182** (시범값)
- **[R6]** 홀소리 앞 /s/ → 위에 적은 문맥별 위치형으로 갈음 (시범규칙)

## 아직 미결인 것

- **[R5]** 힘주기 표 너머의 모음 사이 /l/ — 코드는 ㄹ 을 겹쳐 적는다
  (hello → ᄒᆞᆯ로우). 문서 예시는 홑 ㄹ(ᄒᆞ로우). 코드 계보를 지켰다.
- **[R7]** 좁은 표기 feel 의 마디 가르기.
- 규격 자체의 미결: /θ ð tʃ dʒ/ 의 **종성 부호열 미정**(제5조의2 ⑥) —
  초성형으로 버티고 경고 대상으로 남는다. /v f w z ʒ/ 종성은 종성 시험 중이며
  `love /lʌv/` 의 ᇦ(U+11E6) 은 잠정값이다. `[ʔ]` 는 비어 있다.
- `js/map.js` 의 `SUPPLEMENT` — i, ɝ, ɚ, ts 는 아직 등록부에 행이 없어
  보충값을 쓴다. 해례 R9 의 r 색채 모음 행이 등록부로 옮겨지면
  `articulation.js` 의 `ər` 예외와 함께 사라진다.

**일부러 넣지 않은 것:** 낱말 가운데 종성을 다시 쓰는 처리와 겹자음화.
규격이 정한 바가 없고 `hmbr_convert.py` 도 하지 않는다. 그래서 chicken 은
가운데 /k/ 를 초성 그대로 둔다.

## 두 축

|            | 낱말 모드 | 이어말하기 |
|------------|-----------|------------|
| **넓은 표기(음소)** | 사전 표시 — 기본값 | + 이어말하기 IPA 변형 |
| **좁은 표기(음성)** | + 어두운 ㄹ, /s/ 뒤 이음 자모, ɫ | + 이음매의 어두운 ㄹ이 풀릴 수 있다 |

넓은/좁은은 엔진 옵션(`convert(ipa, { narrow })`)이다. 이음(allophone)은
넓은 표기의 결과에 섞여 들어오지 않는다(제3조 ②). 사전이 [ɫ] 로 적어 와도
음소 모드에서는 /l/ 로 접는다.

낱말/이어말하기는 엔진 옵션이 아니라 앞단의 한 켜다. 규칙은
`js/connected.js` 에 있고 IPA → IPA 로만 움직인다. 낱말 모드는 그저 부르지
않으므로 사전 꼴이 저절로 지켜진다. 지금 든 규칙은 연음 L 하나
(fʊl əv → fʊ‿ləv, 이음줄 ‿ 사용).

변하지 않는 원칙: **AI 는 훈민바름을 내지 않는다.** AI 는 IPA 까지만 대고,
훈민바름 부호열은 결정적 엔진이 만든다.

## 남은 한계

- KS X 1026-1 은 초성+종성만의 조합을 받지 않는다. 그래서 홀로 선 초성은
  채움 중성 U+1160 을 세우고, 홀로 선 종성은 U+115F U+1160 을 앞세운다.
- 유니코드에 등재된 자모만 쓸 수 있다.
- 옛한글이 제대로 쌓이려면 딸린 글꼴이 있어야 한다. 음절이 풀어져 보이면
  woff 를 줄일 때 빠진 글자가 없는지 먼저 본다.
